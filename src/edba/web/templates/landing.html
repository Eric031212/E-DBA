{{ icon('shield') }} Data stays sovereign

Each organization runs its own APIs. E-DBA only routes policy-checked requests; private services are never exposed outside the home workspace.

{{ icon('users') }} Tiered roles

Two-stage registration review, O-Conveners per organization, and three nested access levels for data users — public, private consumption, private provision.

{{ icon('plug') }} No-code connectors

Level-3 providers describe an endpoint with a URL and a JSON schema; the forms, batch uploads and result tables are generated from it.

{{ icon('cash') }} Metered and settled

Per-use prices, quotas and membership fees, settled through idempotent bank transfers recorded in a ledger.

{{ icon('log') }} Tamper-evident audit

Logins, reviews, payments and every service call land in a SHA-256 hash chain that admins can verify in one click.

{{ icon('globe') }} Cross-campus discovery

Browse every member's workspace; visitors see public data only — courses and theses — at the owner's terms.
